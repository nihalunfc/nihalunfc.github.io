Swarm Intelligence

Many real operations are really thousands of small decisions made at the same time: when each battery charges, where each drone flies, which room each attendant cleans next. I built one engine that lets every one of those decision-makers think for itself while working toward a shared goal, so the whole group behaves like a well-coordinated team. It is the same idea as a flock of birds or a colony of ants.

How it works

One shared "brain", many independent members.

No central bottleneck

Each member decides from its own local view, so the system keeps working when there are thousands of members, or when one drops out.

One model, any size

Every member uses the same model. A battery swarm trained with 10 batteries ran unchanged with 100 and 1,000, and still delivered the same 949 MW peak cut.

Team goal, not selfish goals

Members are rewarded for the team result (a flatter grid, less forest burned, fewer guests waiting), so they learn to cover for each other.

Honest testing

Every result is measured on data or scenarios kept aside while building, and compared with today's practice and the best simple rule. Where the swarm loses, the pages say so.

Two kinds of swarm

Learned swarm

Members learn by trial and error in a simulator (multi-agent reinforcement learning). They can also start by copying a good human rule and then improve on it. This is used for batteries, drones, hotel equipment and room attendants.

Market swarm

Members bid for tasks or resources based on what they are worth to the team, like a quick internal auction. The best combination of bids wins. This is used when a fair price can be worked out directly: walked hotel guests bidding for sister-hotel rooms, and staff bidding for open shifts.

Under the hood

  • Python and PyTorch, with one engine shared by all domains, each added as a small plug-in.
  • Shared-parameter Q-networks with team-reward mixing (VDN and QMIX-style), Double DQN, n-step returns and action masks for hard rules.
  • Optional attention-based messages between nearby members.
  • Learning from demonstrations: pre-training on a rule's moves before reinforcement learning.
  • Auction and contract-net markets, checked against exact optimisation (integer programming).
  • Batched across members and parallel simulators, so training cost barely grows with swarm size.

The engine's source code is private. These pages publish its results.
