      Storage and backup

      How to connect your Sheet (about 5 minutes, once)
      1. Make a new Google Sheet in your Drive and name it, for example To-do lists.
      2. In the Sheet, open Extensions › Apps Script. Delete what is there and paste in sheet-backend.gs. Save.
      3. Pick setup in the function menu and press Run. Allow access to your own Sheet when Google asks. It makes the Lists, Items and Snaps tabs, formats them, and prints your secret key in the log.
      4. Press Deploy › New deployment, type Web app, execute as Me, who has access Anyone. Copy the web app address.
      5. Paste the address and the key above and press Connect and sync. Lists already in this browser are copied to the Sheet.

      "Anyone" only means the address answers without a Google sign-in. Without your secret key it returns nothing and changes nothing. To lock it out, run newKey in Apps Script and paste the new key here.

      You can also type straight into the Sheet: add a row on the Items tab with a list name and a task. Set its status to done and it moves to Snaps on the next sync.
