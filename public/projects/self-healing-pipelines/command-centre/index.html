Demo with simulated data. Everything below is a scripted night of a daily pipeline playing at high speed. The buttons work on the demo: pause or stop the crew or one incident, approve a step, revert any logged step, or rework from it. No agent gives orders: each one watches the shared board and claims the incidents in the state it handles.

To run it live: nothing here is connected yet. Point the page at a small API over your board tables (/api/board), with Dagster at DAGSTER_GRAPHQL_URL, the warehouse through a read-only login, the ledger in your pipeline's git repository and a Claude API key with a spend limit. The setup guide lists every connection point.
