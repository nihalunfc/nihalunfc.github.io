Three reference stacks

A. Microsoft medium company (M365, Power BI users): Graph ingest → Dagster on a VM (or ADF) → Azure SQL (serverless GP, columnstore facts) → dbt-sqlserver → Power BI Pro, RLS, subscriptions. Identities: managed identity + Key Vault.

B. Open-source low-cost (no licences, 1–3 data people): dlt + Python landers → Dagster OSS → MinIO/Blob raw Parquet → Postgres (+ DuckDB) → dbt-postgres → Metabase/Superset + Python email reports; Ollama for documents. One or two VMs, Docker Compose. (Week 7, Day 46.)

C. Scale-up (many teams, large event data): Airbyte/Fivetran → Airflow or Dagster+ → Snowflake/BigQuery/Databricks or ClickHouse for events → dbt → Power BI/Looker/Tableau; Iceberg/Delta lake.

All three share the same ideas: immutable raw, idempotent loads, business dates, contracts and quarantine, star schemas, one metric dictionary, missing ≠ zero. That's what makes you portable across them.
