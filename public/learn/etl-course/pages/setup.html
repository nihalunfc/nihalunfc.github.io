Accounts

  • Azure free account for Azure SQL Database (free offer), Key Vault and Blob. Set a budget alert on day one. Delete resources you don't need at the end of each week.
  • Optional: a Microsoft 365 developer or trial tenant for Graph mail/SharePoint and Power BI service practice. If you can't get one, every lab has a local alternative.
  • A throwaway Gmail with an app password for IMAP practice.

Course data

mkdir p2d && cd p2d
# copy starter/generate_data.py from this site's folder
uv venv && uv pip install pandas numpy openpyxl
uv run python generate_data.py --start 2026-09-01 --days 60 --out ./data

Options: --days (length), --seed (different random data), --clean (no seeded faults; useful for checking a pipeline before turning faults back on).

Rules for the whole course

  1. Synthetic or public data only. No employer names, systems, files or figures.
  2. Secrets in .env (git-ignored) or a vault. Run gitleaks before any push.
  3. Type the code; don't paste it. When Claude Code writes something, you must be able to explain each line.
  4. Every day ends with a commit and three lines in My notes.
