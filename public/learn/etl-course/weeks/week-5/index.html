Week 5. Model it in SQL

Star schemas, SCD2, advanced SQL, dbt, semantic layer. Multi-brand restaurants.

Tables are not a model. This week you design star schemas at the right grain, handle history with SCD Type 2, write the SQL that senior analysts write (windows, gaps-and-islands, cohorts), and manage it all with dbt wired into Dagster.

Sector: the multi-brand restaurant group again, now joined with menu, store and calendar dimensions.

Proof project 5: restaurant-dbt: a tested, documented dbt star schema (sales fact, menu/store/date dimensions, SCD2 on menu price) orchestrated by Dagster.
