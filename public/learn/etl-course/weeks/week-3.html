Week 3. Orchestrate with Dagster

Assets, resources, partitions, sensors, checks. Hotel group.

A script you run by hand is a chore. A pipeline that runs itself, retries, waits for files, backfills history and tells you when something is wrong is a system. This week you rebuild your ingest and cleaning code as Dagster assets.

Sector: a five-hotel group (nightly PMS booking extracts, cancellations that arrive as updates, files that land half-uploaded).

Proof project 3: hotel-dagster: a partitioned, sensor-driven Dagster project with asset checks, retries, and a backfill you can demonstrate.
