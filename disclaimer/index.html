Your data and privacy

The free tools run entirely in your web browser. What you type or upload is saved only on your own device (browser local storage) and is never sent to a server. Pressing a reset button, or clearing this site's data in your browser, removes it. This site has no accounts, no tracking cookies and no analytics. The tools have their own detailed privacy notice below.

Tools: privacy, offline use, versions and licence

This applies to every tool under Tools, starting with the Expense calendar.

What we collect

Nothing. The tools have no accounts, no sign-up, no analytics, no advertising, no tracking cookies and no server of their own. The expenses, amounts, notes and settings you enter never leave your device. Nihal cannot see them, collect them or recover them.

The one thing your device does is load the page from this website, and later check it for a newer version when you press Check for updates. That is an ordinary web request. The site is hosted on GitHub Pages, so GitHub handles that request the way it handles any visit to any website (it sees things like your IP address and browser type). Nihal does not get these logs. GitHub's own privacy statement applies to them.

The tool pages load no fonts, scripts or images from any other company.

Where your data lives

  • On your device only, in this browser's local storage. Another browser or device starts empty.
  • It stays until you remove it. Only the reset buttons in the tool, or clearing this site's data in your browser settings, delete it. Each reset clears one part and can be undone for a few seconds.
  • Light or dark theme. If you switch the site to the dark theme, that one choice is also remembered in this browser (as "nihal.theme") so every page opens the same way. It holds nothing else.
  • Optional passcode lock. The tool can encrypt your data on your device with AES-256-GCM, using a key made from your passcode (PBKDF2 with SHA-256, 310,000 rounds). The passcode is never stored. Nobody can open the data without it, including Nihal. A forgotten passcode cannot be recovered.
  • Backups and downloads are your files. A backup made while the lock is on is encrypted. Images and CSV files are not encrypted, so keep them somewhere safe.

Install it and use it offline

Each tool can be installed as an app on a phone, tablet or computer (Add to Home Screen, or the install button in Chrome and Edge). After the first visit it works with no internet connection. The installed app is the same page, so the same privacy rules apply.

Updates and older versions

The tool never changes on you. A new version is downloaded in the background but is only used when you press Update now. Every released version stays online at its own address (for example version 1), so you can keep using whichever version you prefer. All versions read the same saved data.
